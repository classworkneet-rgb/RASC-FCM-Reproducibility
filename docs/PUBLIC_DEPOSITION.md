# Public code deposition

Repository: https://github.com/classworkneet-rgb/RASC-FCM-Reproducibility

The public snapshot is limited to text source code, frozen protocols, seeds, ordered masks, optimizer settings, data/partition manifests and checksums. Actual row-index and split arrays, traffic feature rows, fitted preprocessing arrays, detailed results, model/probability arrays, numeric result figures and author documents are excluded. The complete research package contains the replay evidence and arrays separately. No DOI or GitHub release asset is claimed.

Frozen configurations and digests permit verification of independently regenerated inputs. Exact evaluated source-row selections and client index arrays are supplied in the complete archive. The public mask manifest contains configuration and mask data only, without classification metrics, validation logs or predictions.
